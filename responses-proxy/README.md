# Hermes Bridge extension

The Hermes Bridge extension sends stable chat metadata to the session proxy and displays responses in the current chat. The session proxy server and the tested local text-only setup are documented in the repository [Quick Start](../docs/public-docker-quickstart.md).

## Build and tests

```sh
npm ci
npm run test:unit
npm run build
```

`dist/` is generated by the production build and is not committed. Copy `manifest.json` and the generated `dist/` directory into SillyTavern's third-party extension directory to install a local build.

The extension source includes optional UI components beyond the text-only Quick Start; voice and workspace flows are not supported by that Compose setup.
